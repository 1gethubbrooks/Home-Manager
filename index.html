⚙️ Google Calendar Setup
One-time free setup — takes about 5 minutes
Step 1. Go to console.cloud.google.com
Step 2. Create a new project (e.g. "Home Manager")
Step 3. APIs & Services → Enable APIs → enable Google Calendar API
Step 4. APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID
Step 5. Application type: Web application
Step 6. Authorized JS origins: add your GitHub Pages URL
Step 7. Copy the Client ID it gives you
Step 8. Paste it below and tap Save
